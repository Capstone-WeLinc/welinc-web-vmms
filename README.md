# WeLinc VMMS Web Admin

A React + Vite frontend for the VMMS web admin.

## Setup

1. Install dependencies:

   ```powershell
   npm install
   ```

2. Copy the environment example:

   ```powershell
   copy .env.example .env
   ```

3. Start the dev server:
   ```powershell
   npm run dev
   ```

The app expects the backend to run at `http://localhost:3000`.

## Available pages

- `/login`
- `/dashboard`
- `/User Management`
- `/Maintenance Scheduling`
- `/Work Orders`
- `/Checklist Template`
- `/Maintenance Logs`
- `/Maintenance Reports`
- `/Fuel Expense`
- `/Maintenance Expense`
